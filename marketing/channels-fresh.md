# Free distribution channels for a fresh project (day-one friendly)

Researched 2026-08-10. Every channel below is **free** and accepts projects with
**no meaningful age requirement** — the "fresh project" bar. One day of work,
~30 minutes per channel. Order matters: Tier 1 first, Tier 2 when Tier 1 is
done, set-and-forget in the background.

**The rule that got us this far:** channels with age gates (like
`lorien/awesome-web-scraping`'s 6-month rule) or pay-to-play-first are skipped
on purpose. Everything here is day-one legal.

### Tier 1 details worth knowing

- **Open Source Friday is the sleeper hit here.** It's GitHub's own channel,
  explicitly "open year-round," and the ask is a guest issue, not a pitch email.
  scrape-heal's demo is visual (GIF + live preview), which is exactly what a
  livestream wants. Schedule is visible in the repo README — the next slot is
  what you'd apply for.
- **Console.dev** has ~20k subscribers of exactly this audience (devtools).
  Free submission goes through the contact address; keep the pitch to: what it
  is, the problem, the verify-then-ship hook, the repo link.
- **DEV.to** is the highest-organic-yield platform of the batch — its trending
  algorithm promotes engagement, and the CTO post is already written. Post it
  as-is, GIF first.

## Set-and-forget (automatic, zero effort after setup)

- **gitlogs.com (GitHub News)** — auto-detects trending repos; just have decent
  metadata (description, topics).
- **Best of JavaScript** — auto-tracks popular JS/TS OSS; stars feed it.
- **GitHub Explore / Topics** — per the Preevy playbook, topics must be added
  by someone **not** connected to the project — ask a friend who likes the tool
  to add `self-healing` / `web-scraping` / `playwright` topics.
- **daily.dev** — get a blog approved as a content source, then every post you
  publish distributes automatically.
- **Lobsters** — invite-gated; if a friend has an invite, the technical
  audience is a strong fit.

## The 100-stars bootstrap (why stars matter first)

From the Preevy playbook (1.5k stars in 12 weeks): GitHub **trending** is driven
by star velocity, so the first ~100 stars come from close to home — a friendly
message to relevant people in your network asking them to check it out and
star, and a launch announcement on your own social channels. Do this *before*
the Tier 1 submissions so the repo doesn't look empty when newsletters and
communities click through.
